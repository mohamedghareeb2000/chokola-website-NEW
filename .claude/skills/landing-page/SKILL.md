# Landing Page Skill

## Goal
Create landing pages that communicate the value proposition quickly and guide users toward the intended action.

## Standard Structure
Use only sections that support the actual goal. Common sections:
1. Navigation
2. Hero
3. Brand/value proposition
4. Key benefits/features
5. Product/menu/content showcase
6. Social proof
7. Location/branches/contact where relevant
8. Final CTA
9. Footer

Do not add sections simply to make the page longer.

## Hero
The hero should quickly communicate:
- what the brand/product is
- why it matters
- primary action
- secondary action when useful
- strong visual identity

Avoid overcrowding the hero.

## CTA
- Use clear action language.
- Make primary and secondary actions visually distinct.
- Ensure CTA remains usable on mobile.
- Avoid competing CTA buttons with equal visual weight.

## Content Rhythm
Alternate dense and spacious sections.
Use consistent container widths.
Create visual transitions without excessive decoration.

## Conversion
Ask:
- Can a first-time visitor understand the offer quickly?
- Is the primary action obvious?
- Is there unnecessary friction?
- Are trust signals available where needed?
- Does the page answer likely objections?

## Performance
- Optimize hero imagery.
- Avoid unnecessarily heavy animation.
- Lazy-load below-the-fold media when appropriate.
- Do not sacrifice usability for visual effects.

## Responsive
Every section must have an intentional mobile layout, not merely a scaled desktop layout.
